Release 1.0.0 — primeira versão estável.

Marca o compromisso de versionamento SemVer estrito sobre a superfície pública: interfaces, tipos, error classes e DI symbols extraídos do ts-express-app. Mudanças incompatíveis a partir daqui exigem novo major.

Conteúdo funcional idêntico ao primeiro publish (0.0.1) — esta release formaliza o contrato de API e inaugura o modelo de release por branch dedicada (`releases/<package>/v<version>`) descrito no Addendum 2026-04-22 do ADR-0001.
